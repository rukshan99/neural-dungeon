Phase 1 is small: `relevance_gate` is `bool(scores) and max(scores) >= threshold`; `calibrate_threshold` is `float((np.percentile(on, 10) + np.percentile(off, 90)) / 2)`. Phase 2 starts with `content_words`: remove the markers with `re.sub(r"\[\d+(?:\s*,\s*\d+)*\]", " ", text)`, then `set(content_tokens(text))` from the assets does the lowercasing, punctuation, stopwords and stemming.
---
`citation_supported`: `words = content_words(sentence)`; empty means False; otherwise `len(words & content_words(chunk)) / len(words) >= min_overlap`. `verify_citations`: for each `sentence in split_sentences(answer)`, for each `n in parse_citations(sentence)`: out of `1..len(sources)` is invalid; else `ok[n] = ok.get(n, True) and citation_supported(sentence, sources[n - 1], min_overlap)`. Keep a list of numbers in first-appearance order and sort them into the three columns at the end.
---
`GroundedRAG.answer`: retrieve k; `if not relevance_gate([s for _, s in retrieved], self.threshold)` return the refusal with `LOW_RELEVANCE` (do not call the model); `text = self.llm.complete(build_prompt(question, retrieved)).text`; `report = verify_citations(text, [c.text for c, _ in retrieved])`; no `valid` means refuse with `NO_SUPPORTED_CITATION`; otherwise strip each failed marker with `re.sub(rf"\s*\[{n}\]", "", text)` and return `citations = [chunks[n - 1].id for n in report["valid"]]`, `refused=False`, `reason=None`. For the prophecy: the gate sees only scores and runs first; the verifier sees only words; a word-for-word copy with one number changed satisfies both.
