A leaf is a tensor you created yourself: `t = torch.tensor(3.0, requires_grad=True)`. Anything computed from it has a `grad_fn` and is not a leaf. `y.backward()` fills `t.grad` (and only leaves get a `.grad`). `t.grad.item()` turns the 0-d tensor into a float. For the prophecy, remember that `.grad` adds up, that in-place ops on a tracked leaf are refused outside `no_grad`, and that `.numpy()` refuses anything with a graph.
---
`accumulate_twice`: build `(t ** 2)` twice and call `.backward()` on each; do not touch `t.grad` in between. `zero_then_backward`: set `t.grad = None` between them. `frozen_copy`: `t.detach()` shares storage; `t.detach().clone()` does not (`t.clone()` alone is still tracked, so detach first). `no_grad_eval`: `with torch.no_grad(): return f(x)`.
---
`manual_sgd_step`: `with torch.no_grad(): w -= lr * grad` (or `w.sub_(lr * grad)`). The in-place operator keeps `w` the same object, which is why the caller sees the change. Prophecy answers, in order of the rules in the docstring: rule 2 -> RuntimeError; rule 5 -> RuntimeError; numpy -> RuntimeError; the no_grad step computes `[1 - 1, 2 - 2]`; rule 1 gives `6 + 6`; `y.detach()` is a constant 6, so dz/dx is 6.
