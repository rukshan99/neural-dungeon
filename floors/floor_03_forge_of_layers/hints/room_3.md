`iterate_minibatches`: `order = rng.permutation(n) if shuffle else np.arange(n)`, then `for start in range(0, n, batch_size): yield order[start:start + batch_size]`. Slicing past the end just gives a shorter last batch, which is exactly what you want. `Sequential.forward` is a for loop over `self.layers`; `backward` is the same loop over `reversed(self.layers)`, threading `dout` through.
---
`params()` is a dict comprehension: `{f"{i}.{name}": p for i, layer in enumerate(self.layers) for name, p in layer.params.items()}`; `grads()` is the same over `layer.grads`. `SGD.step`: `for name, p in self.params.items(): g = grads[name]; if self.weight_decay and p.ndim >= 2: g = g + self.weight_decay * p; p -= self.lr * g`. The `-=` is not optional: it writes into the model's array.
---
`train`: for each epoch, `model.train()`, `total = 0.0`, then per batch `idx`: `model.zero_grad()`, `logits = model.forward(X[idx])`, `L = loss.forward(logits, y[idx])`, `model.backward(loss.backward())`, `opt.step(model.grads())`, `total += L * len(idx)`; append `total / len(X)`. `accuracy`: remember `model.training`, `model.eval()`, `pred = model.forward(X).argmax(axis=1)`, restore with `model.train()` if it was training, return `float(np.mean(pred == y))`.
