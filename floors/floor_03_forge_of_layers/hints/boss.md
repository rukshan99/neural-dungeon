Phase 1. `l2_penalty`: `0.5 * weight_decay * sum(np.sum(p**2) for p in params.values() if p.ndim >= 2)`, wrapped in `float()`. `Dropout.forward` in train mode: `keep = self.rng.random(x.shape) >= self.p`; `self.cache = keep / (1 - self.p)`; `return x * self.cache`. In eval mode (or `p == 0`) set `self.cache = None` and return `x`. `backward`: `return dout if self.cache is None else dout * self.cache`.
---
Phase 2. `count_heads`: predict in eval mode (`model.eval()`, `pred = model.forward(X_train).argmax(axis=1)`, restore the mode), then `flipped = y_noisy != y_clean` and `return int(np.sum(flipped & (pred == y_noisy)))`. Run `dungeon fight 3` once with only phases 1 and 2 done: the wild-hydra test prints how many heads an unregularized model grows, so you know what you are up against.

Phase 3. Build a `[2, 64, 64, 3]` ReLU MLP with `he_normal` weights (`lin.params["W"][...] = he_normal(fan_in, fan_out, rng)`), `SGD(model.params(), lr=0.2, weight_decay=1e-3)`, and `train_with_validation(model, loss, opt, X_train, y_noisy, X_val, y_val, epochs=800, batch_size=16, rng=rng, patience=50)`. Then `model.eval()` and return it. Weight decay taxes the sharp weights that carve out a single memorized point; early stopping quits while the model still knows the spiral and not yet the lies. Try `Dropout(0.1)` after each ReLU and watch what it does to the head count and the val accuracy; on a net this small it may cost more than it saves.
