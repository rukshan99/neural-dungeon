Forward stores, backward reads. `Linear.forward` needs to remember `x` (that is all `dW` needs); `ReLU.forward` should remember the mask `x > 0`; `Tanh.forward` should remember its own output. `SoftmaxCrossEntropy.forward` should remember the probabilities and `y`. Then every backward is one or two lines that read `self.cache`.
---
Shapes tell you where the transposes go. With `x (N, in)`, `W (in, out)`, `dout (N, out)`: the only way to get `(in, out)` is `x.T @ dout`; the only way to get `(N, in)` is `dout @ W.T`; `db` is `(out,)`, so sum `dout` over `axis=0`. Use `+=` into `self.grads` (gradients accumulate; `zero_grad()` clears them). For the loss: `shifted = logits - logits.max(axis=1, keepdims=True)`, `log_probs = shifted - np.log(np.exp(shifted).sum(axis=1, keepdims=True))`.
---
`Linear.backward`: `self.grads["W"] += x.T @ dout; self.grads["b"] += dout.sum(axis=0); return dout @ W.T`. `ReLU.backward`: `return dout * mask`. `Tanh.backward`: `return dout * (1 - out**2)`. Loss forward: `probs = np.exp(log_probs)`, `loss = -log_probs[np.arange(N), y].mean()`, cache `(probs, y)`, return `float(loss)`. Loss backward: `d = probs.copy(); d[np.arange(N), y] -= 1; return d / N`.
