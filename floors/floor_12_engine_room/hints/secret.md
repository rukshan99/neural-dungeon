One forward over `prompt + draft` gives logits at every position. The logit row at index `T - 1 + j` is the model's prediction after seeing `prompt + draft[:j]`, i.e. exactly what greedy would have emitted at that step. Compare `draft[j]` with `argmax(logits[T - 1 + j])` for j = 0, 1, ... and stop at the first mismatch. Everything before it is accepted; the argmax at the mismatch (or after the whole draft) is the one token the model contributes itself.
---
`propose_from_prompt`: `pattern = ids[-n:]`; `for start in range(len(ids) - n - 1, -1, -1): if ids[start:start + n] == pattern: return ids[start + n : start + n + k]`; return `[]` if nothing matches or `len(ids) <= n`. Starting the search at `len(ids) - n - 1` is what keeps the pattern from matching itself.
---
`speculative_generate`: `target = min(max_new_tokens, block_size - T0)`; loop while `generated < target`: `T = idx.shape[1]`; `draft = propose_from_prompt(idx[0].tolist(), n, k)[: min(remaining - 1, block_size - T - 1)]` (clamped at 0); `candidate = cat(idx, draft)`; `logits, _ = model(candidate)`; `greedy = logits[0, T - 1:].argmax(-1).tolist()`; count `accepted` while `draft[j] == greedy[j]`; `new = draft[:accepted] + [greedy[accepted]]`; append `new` to `idx` and `len(new)` to `generated`. Each round is one forward pass and at least one token.
