Left padding puts every row's newest token in the last column, so `logits[:, -1]` is the next-token distribution for every row and decoding appends one column to the batch. The two things that make the pads harmless: position ids that start at 0 at each row's first real token, and an attention mask that is `causal AND key-is-real`, applied as `-inf` BEFORE the softmax so padded keys get weight exactly 0.
---
`left_pad`: `T = max(len(s))`; `idx = torch.full((B, T), pad_id)`; fill `idx[b, T - len(s):]` and `mask[b, T - len(s):] = True`; `position_ids = (mask.cumsum(1) - 1).clamp(min=0)`. `forward_masked`: `allowed = torch.tril(torch.ones(T, T, dtype=bool))[None, None] & attention_mask[:, None, None, :]` has shape `(B, 1, T, T)` and broadcasts over heads. In `masked_attention`: `att.masked_fill(~allowed, float("-inf"))`, softmax, then `torch.nan_to_num(att, nan=0.0)` for the padded queries that saw only -inf.
---
`batched_greedy_generate`: `idx, mask, pos = left_pad(prompts, 0)`; `n = min(max_new_tokens, block_size - T)`; each step `logits = forward_masked(model, idx, mask, pos)`, `next_ids = logits[:, -1].argmax(-1)`; append to each unfinished row's list unless it equals `eos_id` (then mark the row finished); then `idx = cat([idx, next_ids[:, None]], 1)`, `mask = cat([mask, ones(B, 1, bool)], 1)`, `pos = cat([pos, pos[:, -1:] + 1], 1)`. Break early when every row is finished. Return the per-row lists, nothing else.
