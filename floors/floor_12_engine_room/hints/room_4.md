Nearest rank: sort the samples, compute `rank = ceil(p / 100 * n)` (1-based), return `sorted[max(rank, 1) - 1]`. It never averages two samples, so the result is always a latency that actually happened. p50 of 1..100 is 50, p95 is 95, p99 is 99, p0 is the minimum and p100 the maximum.
---
`LatencyMeter` keeps three lists: `durations` (seconds), `tokens`, `ttfts`. `record(duration_s, tokens, ttft_s=None)` appends (ttft only if given). `request()` returns a `RequestTimer(self)`. In the timer: `__enter__` stores `time.perf_counter()` and returns `self`; `first_token()` sets `self.ttft = perf_counter() - t_start` only if it is still None; `__exit__` computes the duration and calls `meter.record(duration, self.tokens, self.ttft)`. `summary()` converts durations to ms (`d * 1000`) before `latency_summary`, and `tokens_per_second = throughput(sum(tokens), sum(durations))`.
