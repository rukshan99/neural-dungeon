Symmetric absmax: `scale = absmax / 127`, `q = round(w / scale)`, `w_hat = q * scale`. Because the largest |w| maps to exactly 127, nothing is clipped and every weight is within `scale / 2` of the original. Per-channel means "one scale per output row", i.e. `w.abs().amax(dim=1, keepdim=True)` with shape `(out, 1)`; per-tensor is `w.abs().amax().reshape(1, 1)`. Keeping the scale as a column is what lets `q.float() * scale` broadcast back without any reshaping.
---
`quantize_int8`: `w = w.detach().float()`; compute `absmax`; `scale = (absmax / 127).clamp(min=1e-8)`; `q = torch.round(w / scale).clamp(-127, 127).to(torch.int8)`. `QuantizedLinear.__init__`: call `super().__init__()`, quantize `linear.weight`, `self.register_buffer("weight_q", q)`, `self.register_buffer("scale", scale)`, keep `linear.bias` as float32 (or None). `forward`: `F.linear(x, dequantize(self.weight_q, self.scale), self.bias)`.
---
`quantize_model_linears`: `qmodel = copy.deepcopy(model)`; `targets = [(name, m) for name, m in qmodel.named_modules() if isinstance(m, nn.Linear) and name != "lm_head"]`; for each, `parent_name, _, attr = name.rpartition(".")`, `parent = qmodel.get_submodule(parent_name)`, `setattr(parent, attr, QuantizedLinear(m, per_channel))`. Return `(qmodel, len(targets))`; expect 16. Prophecy: 4 int8 weights per fp32 weight; per-tensor has the larger error on the quiet rows; every row's absmax becomes |127|; `lm_head.weight is wte.weight`, so the tied tensor is `wte`; dequantizing on the fly saves memory only.
