The template is just string concatenation: `render_chat` maps `"user"` to `USER_TAG` and `"assistant"` to `ASSISTANT_TAG` (raise `ValueError` otherwise) and returns `"".join(tag + text + END_TAG for each turn)`; `render_prompt(q)` is `render_chat([("user", q)]) + ASSISTANT_TAG`. `make_instruction_pairs`: `re.match(r"^item: (.+?) \| qty: (\d+) \| price: (\d+) ([a-z]+) \| note: (.*)$", line)` on each line of the ledger, skip non-matches, stop after `n`.
---
`build_sft_example`: `prompt_ids = tokenizer.encode(render_prompt(prompt))`, `response_ids = tokenizer.encode(response + END_TAG)`, raise if `len(response_ids) >= max_len`, `ids = prompt_ids + response_ids`; if too long, `dropped = len(ids) - max_len; ids = ids[dropped:]; n_prompt = len(prompt_ids) - dropped`. Then `labels = torch.full_like(input_ids, -100)` and `labels[n_prompt - 1 : -1] = input_ids[n_prompt:]`. `collate_sft`: `torch.full((B, T_max), pad_id)` / `torch.full((B, T_max), -100)` and copy each example into `[:len]`. `sft_loss`: `F.cross_entropy(logits.reshape(-1, V), labels.reshape(-1), ignore_index=-100)`.
---
`finetune_sft` is Room 3's `finetune` with a different batch: `ix = torch.randint(0, len(pairs), (batch_size,), generator=generator)`, `examples = [build_sft_example(*pairs[i], tokenizer, max_len) for i in ix.tolist()]`, `x, y = collate_sft(examples, tokenizer.unk_id)`, `logits, _ = model(x)`, `loss = sft_loss(logits, y)`. `evaluate_sft`: same batches under `@torch.no_grad()` in eval mode, `reduction="sum"` divided by `(labels != -100).sum()`. `answer`: `idx = torch.tensor([tokenizer.encode(render_prompt(prompt))])`, loop `logits, _ = model(idx[:, -block_size:])`, `next_id = logits[:, -1].argmax(-1, keepdim=True)`, append, decode the generated ids, stop when the text `.endswith(END_TAG)` and return it without the tag.
