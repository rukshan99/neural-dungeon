`sequence_logprob`: `logits, _ = model(ids)`; `logp = F.log_softmax(logits[:, :-1], dim=-1)` (position t-1 predicts ids[:, t]); `per_token = logp.gather(-1, ids[:, 1:].unsqueeze(-1)).squeeze(-1)`; return `per_token[:, prompt_len - 1:].sum(-1)`. `dpo_loss`: `chosen_reward = beta * (policy_chosen - ref_chosen)`, same for rejected, `loss = -F.logsigmoid(chosen_reward - rejected_reward).mean()`; return the rewards `.detach()`ed. `frozen_reference`: `copy.deepcopy`, `requires_grad_(False)` on every parameter, `.eval()`.
---
`make_preference_pairs`: encode once, `starts = torch.randint(0, len(data) - L + 1, (n,), generator=generator)`, `chosen = torch.stack([data[s:s+L] for s in starts.tolist()])`, `rejected = chosen.clone()`, then per row draw `r = int(torch.randint(0, len(data) - response_len + 1, (1,), generator=generator))`, redraw while `torch.equal(data[r:r+response_len], chosen[row, prompt_len:])` (the corpus repeats itself, so compare content), and set `rejected[row, prompt_len:] = data[r:r+response_len]`. `dpo_step`: reference log-probs under `torch.no_grad()`, policy log-probs with the graph, `dpo_loss`, `optimizer.zero_grad(set_to_none=True)`, `loss.backward()`, `optimizer.step()`, return the floats (`margin = (chosen_reward - rejected_reward).mean()`, `reward_accuracy = (chosen_reward > rejected_reward).float().mean()`).
---
`train_dpo`: `opt = torch.optim.AdamW([p for p in policy.parameters() if p.requires_grad], lr=lr)`, remember `policy.training`, call `policy.eval()` (dropout off; gradients still flow), then per step `ix = torch.randint(0, n, (batch_size,), generator=generator)`, `batch = {"chosen": pairs["chosen"][ix], "rejected": pairs["rejected"][ix], "prompt_len": pairs["prompt_len"]}`, `history.append(dpo_step(...))`; restore the mode. If your first loss is not 0.693, the policy is in train mode. `evaluate_preferences`: the same four log-prob calls under `@torch.no_grad()` in chunks, summing margins, wins and log-probs, divided by the number of pairs.
