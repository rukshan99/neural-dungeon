`assign_arm`: `digest = hashlib.sha256(f"{salt}:{request_id}".encode()).digest()`, `u = int.from_bytes(digest[:8], "big") / 2**64`, and the arm is `"canary" if u < canary_fraction else "baseline"`. Because the same `u` is compared against every fraction, a request in the 5% canary is automatically in the 25% one. Validate the fraction first and raise `ValueError` outside [0, 1].

`compare_arms` is Floor 11's bootstrap with TWO index arrays: `idx_a = rng.integers(0, len(a), size=(n_boot, len(a)))` and `idx_b = rng.integers(0, len(b), size=(n_boot, len(b)))`, then `deltas = b[idx_b].mean(axis=1) - a[idx_a].mean(axis=1)`. The interval is `np.percentile(deltas, [100 * alpha / 2, 100 * (1 - alpha / 2)])` and the p-value is `min(1, 2 * min(np.mean(deltas <= 0), np.mean(deltas >= 0)))`. Convert everything with `float(...)` / `int(...)`. If the arrays are large, loop over `n_boot` in chunks so the index arrays stay small.

`guardrail_check`: loop over `slo.items()`, look each name up with `canary_metrics.get(name)`, and call it ok only when the value is not None and `<= limit`; collect the failing names in order. `release_decision` is four lines in this order: guardrails failed -> "rollback"; `ci_high < 0` -> "rollback"; `ci_low > 0 and delta >= min_effect` -> "promote"; else "extend". `ramp_schedule` checks `steps[-1] == 1.0`, every step in (0, 1], and `all(later > earlier for earlier, later in zip(steps, steps[1:]))`. `advance_ramp`: rollback -> 0.0, extend -> the same fraction, promote -> `next((s for s in schedule if s > fraction), 1.0)`.
