Two formulas carry the room. `discordant_probability`: `b_only = p_b * (1 - p_a)`, `a_only = p_a * (1 - p_b)`, return `b_only / (b_only + a_only)`. `wald_bounds`: `(math.log(beta / (1 - alpha)), math.log((1 - beta) / alpha))`. With alpha 0.05 and beta 0.2 that is about (-1.56, +2.77): the test needs more evidence to declare a winner than to give up, because a false winner is the costlier mistake.
---
`update`: if `self.decision` is already set, return it without counting. Otherwise `self.n_pairs += 1`; if `bool(a_success) == bool(b_success)` return None (concordant pairs carry no information about WHICH arm is better). Else `self.n_discordant += 1` and `self.llr += math.log(self.q1 / 0.5)` when B succeeded, `math.log((1 - self.q1) / 0.5)` when A did. Then `if self.llr >= self.upper: self.decision = "b_better"` and `elif self.llr <= self.lower: self.decision = "no_difference"`. Precompute the two step sizes in `__init__` if you like.
---
`feed`: check the lengths match, then `for a, b in zip(a_outcomes, b_outcomes): if self.update(a, b) is not None: break`, and return `self.decision`. `fixed_horizon_pairs`: `z_alpha = NormalDist().inv_cdf(1 - (alpha / 2 if two_sided else alpha))`, `z_beta = NormalDist().inv_cdf(1 - beta)`, `p_b = p_a + min_effect`, `variance = p_a * (1 - p_a) + p_b * (1 - p_b)`, and return `math.ceil((z_alpha + z_beta) ** 2 * variance / min_effect ** 2)`. For 0.80 vs 0.85 that is 711 pairs one-sided; the sentinel averages about 500 when the lift is real and about 280 when it is not.
