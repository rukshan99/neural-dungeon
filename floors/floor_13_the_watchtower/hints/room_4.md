`RollingWindow` is a thin wrapper over the deque that `__init__` already made: `push` appends `float(value)`; `percentile` sorts `self._values`, computes `rank = max(1, math.ceil(p / 100 * n))` and returns `ordered[rank - 1]`; `mean` and `rate` are one-line sums over the values. Every one of them raises `ValueError` on an empty window, and `percentile` also for `p` outside [0, 100].
---
`Threshold.update` is a two-state machine: `if not self.active and value > self.fire_above: self.active = True; return "fired"`; `if self.active and value < self.clear_below: self.active = False; return "resolved"`; otherwise `return None`. The gap between the two lines is what stops the flapping: a value of 0.17 with lines at 0.20 / 0.15 changes nothing in either state.
---
`AlertManager.observe`: look up `threshold, severity = self.rules[name]` (KeyError if missing), `now = float(self.clock())`, `edge = threshold.update(value)`. On `"fired"`: if `name in self.last_fired and now - self.last_fired[name] < self.cooldown`, increment `self.suppressed`; otherwise build `Alert(name, severity, float(value), now, "fire")`, store `self.last_fired[name] = now` and `self._announced.add(name)`. On `"resolved"`: only if `name in self._announced`, build the `"resolved"` alert and `discard` the name. Extend `self.events` with whatever you emit and return it as a list. `error_budget`: `allowed = (1 - slo_target) * window_requests`, `remaining = (allowed - failures) / allowed`, `burn = (failures / window_requests) / (1 - slo_target)`.
