The whole room hangs on the stack. In `Tracer.span`, build the `Span` with `start=self.clock()`, attach it to `self._stack[-1].children` if the stack is non-empty (else `self.traces`), push it, `yield` it inside a `try`, and in `finally` set `span.end = self.clock()` and pop. The `except Exception as exc:` branch sets `span.status = "error"`, stores `type(exc).__name__` under `"error.type"`, and `raise`s again. `record_llm_call` and `record_tool_call` are just `with tracer.span(...) as span:` blocks that write attributes after the call returns.
---
`summarize` is one loop over the provided `walk(trace)`: track `max(depth)`, count `status == "error"`, and for `kind == "llm"` add `duration_ms`, `input_tokens + output_tokens` and `cost_usd` from `span.attributes` (use `.get(key, 0)`); for `kind == "tool"` add the duration and the count. `total_ms` is `trace.duration_ms`. Cost in `record_llm_call`: `usage.input_tokens * input_price_per_million / 1e6 + usage.output_tokens * output_price_per_million / 1e6`, where `usage = completion.usage`.
---
`span_to_dict` returns a literal dict written in FIELD_ORDER: `{"name": ..., "kind": ..., "start": ..., "end": ..., "status": ..., "attributes": dict(span.attributes), "children": [span_to_dict(c) for c in span.children]}`; Python dicts keep insertion order and `json.dumps` preserves it. `span_from_dict` is `Span(name=d["name"], ..., children=[span_from_dict(c) for c in d["children"]])`. `redact_attributes`: `clone = copy.deepcopy(trace)`, `wanted = {k.lower() for k in keys}`, then for every `span, _ in walk(clone)` and every key in `list(span.attributes)`, replace the value when `key.lower() in wanted`. Return the clone.
