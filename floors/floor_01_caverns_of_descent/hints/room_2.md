The oracle is a loop over every element of x. For each index, make a copy of x, nudge that one element up (and, for central differences, another copy nudged down), evaluate f on the copies, and store the quotient in an output array of x's shape. `np.ndindex(x.shape)` yields every multi-index, and works for any number of dimensions, including zero.
---
Skeleton: `grad = np.zeros_like(x, dtype=float)`; `for idx in np.ndindex(x.shape): up = x.copy(); up[idx] += eps; down = x.copy(); down[idx] -= eps; grad[idx] = (f(up) - f(down)) / (2 * eps)`. Forward differences reuse one `f0 = f(x)` and only bump upwards. `gradient_check` calls `numerical_gradient`, then `np.asarray(grad_f(x))`, compares shapes (raise ValueError if they differ), and returns `np.linalg.norm(num - ana) / (np.linalg.norm(num) + np.linalg.norm(ana) + eps)` as a float.
---
For the prophecy, expand f(x + h) = f + h f' + h^2/2 f'' + h^3/6 f''' + ... Forward: (f(x+h) - f(x))/h = f' + (h/2) f'' + ..., error order 1. Central: the h^2 terms cancel, leaving f' + (h^2/6) f''', order 2. Tiny h: f(1 + 1e-12) and f(1 - 1e-12) agree to ~12 digits, so their difference has only ~4 correct digits, and dividing by 2e-12 does not bring them back. eps = 1e-12 is *less* accurate than 1e-5: the answer is False.
