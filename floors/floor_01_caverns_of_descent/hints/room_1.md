Every loss is a mean, so every gradient is the per-element derivative divided by N = `y_pred.size`. Write the scalar derivative first (d/dp of (p - t)^2 is 2(p - t); of |p - t| is sign(p - t); of -(y log p + (1-y) log(1-p)) is (p - y)/(p(1-p))), then broadcast it over the array and divide by N. For the logit losses, never compute exp(z) for large positive z: use `np.logaddexp(0, z)` for softplus and subtract the row max before any exp in log_softmax.
---
Stable pieces: `sigmoid(z) = np.exp(-np.logaddexp(0, -z))` (or `0.5 * (1 + np.tanh(z / 2))`). `bce_with_logits = np.mean(np.logaddexp(0, z) - y * z)`. `log_softmax`: `s = z - z.max(axis=-1, keepdims=True); return s - np.log(np.exp(s).sum(axis=-1, keepdims=True))`. To pick each row's correct-class entry from an (N, C) array: `logp[np.arange(N), labels]`.
---
`mse_grad`: `2 * (y_pred - y_true) / y_pred.size`. `binary_cross_entropy`: `p = np.clip(p, eps, 1 - eps); return float(-np.mean(y * np.log(p) + (1 - y) * np.log1p(-p)))`, and its grad `(p - y) / (p * (1 - p)) / p.size` with the same clipped p. `bce_with_logits_grad`: `(sigmoid(z) - y) / z.size`. `softmax_cross_entropy`: `float(-np.mean(log_softmax(logits)[np.arange(N), labels]))`. Its grad: `g = np.exp(log_softmax(logits)); g[np.arange(N), labels] -= 1; return g / N`.
