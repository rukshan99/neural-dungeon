Phase 1 needs the forward pass to *keep* every pre-activation `z_l = W_l @ x_l`. Then start from `g = np.ones(width)` (that is dL/dx_depth, since the loss is a plain sum) and walk the layers backwards: `g = W.T @ (dact(z) * g)`, recording `np.linalg.norm(g)` before and after each step. Build the list from the last layer to the first and reverse it at the end so `norms[0]` is layer 0. With `use_residual`, add the skip path: `g_new = W.T @ (dact(z) * g) + g`.
---
Phase 2 by estimation: each layer multiplies the squared norm by roughly `init_scale**2 * width * mean(act'**2)`. Every named init is `c / sqrt(width)`, so that is `c**2 * mean(act'**2)`. Sigmoid's derivative is at most 0.25 and `c = 0.5`, so at best 1/64 per layer, squared: a fiftieth power of 1/8. ReLU's derivative is 1 on half the units, so `mean(act'**2) = 1/2`: He's `c**2 = 2` gives exactly 1 (survives), `large`'s `c**2 = 9` gives 4.5 (explodes). Tanh near zero has derivative near 1 and Xavier's `c = 1` keeps it close to, but a little under, 1: it decays slowly and survives 50 layers.
---
Phase 3, the textbook answer: `{"activation": "relu", "init": "he", "use_residual": False}`. The surprising answer: `{"activation": "sigmoid", "init": "small", "use_residual": True}`; the skip connection carries the gradient with factor exactly 1 and the tiny sigmoid branch barely disturbs it. What does NOT work: adding residuals to relu/he. Each residual layer then multiplies the squared norm by about `1 + 1 = 2`, and 2 to the 25th is not a survivor.
