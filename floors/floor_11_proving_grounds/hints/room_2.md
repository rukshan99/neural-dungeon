The bootstrap has one move: draw n indices with replacement, take those elements, compute the statistic, repeat. `rng.integers(0, n, size=(n_boot, n))` gives every resample's indices in one array. For the paired version the trick is that a and b share the SAME index array, so `d = b - a` and `d[idx].mean(axis=1)` gives all n_boot deltas at once. For the prophecy: the standard error of a proportion is `sqrt(p(1-p)/n)`; for a difference, add the two variances and square-root. A gap needs about two standard errors to be told from zero.
---
`bootstrap_ci`: `stats = np.array([statistic(x[row]) for row in idx])` (a loop, because an arbitrary statistic may not accept `axis`), then `np.percentile(stats, [100*alpha/2, 100*(1-alpha/2)])`. `paired_bootstrap`: `low, high = np.percentile(deltas, [2.5, 97.5])` for alpha=0.05, and `p = min(1.0, 2 * min(np.mean(deltas <= 0), np.mean(deltas >= 0)))`. `is_significant`: `low > 0 or high < 0`. `required_sample_size`: `math.ceil(z*z*p*(1-p)/margin**2)`.
---
The prophecy by arithmetic. n=50, 80% vs 84%: SE of the gap is about sqrt(0.8*0.2/50 + 0.84*0.16/50) = 0.077, and the gap is 0.04, so about half a standard error: not distinguishable. n=2000, same gap: SE is 0.012, gap is 3.3 SEs: distinguishable. n=200, 60% vs 75%: SE about 0.046, gap 0.15, more than 3 SEs: distinguishable. Remember `rng = np.random.default_rng(0) if rng is None else rng`, and return Python floats (`float(low)`), not numpy scalars.
