Confidence is the largest softmax probability; a prediction is correct when the argmax equals the label. ECE groups predictions into confidence bins and, in each bin, compares the average confidence with the fraction actually correct. Temperature scaling is a one-dimensional search: for every T in the grid, compute the mean NLL of `softmax(logits / T)` at the true labels and keep the T with the smallest loss. Dividing by T never reorders a row, so accuracy cannot change.
---
Stable softmax: `z = logits / T; z = z - z.max(axis=-1, keepdims=True); e = np.exp(z); e / e.sum(axis=-1, keepdims=True)`. For `mean_nll` stay in log space: `log_probs = z - np.log(np.exp(z).sum(axis=-1, keepdims=True))`, then `-log_probs[np.arange(n), labels].mean()`. Bins: `edges = np.linspace(0, 1, n_bins + 1)` and `idx = np.digitize(conf, edges[1:-1], right=True)` puts each confidence in the bin whose `(lower, upper]` interval contains it.
---
`reliability_table`: start with `np.full((n_bins, 3), np.nan)`, and for each bin `mask = idx == b`, set `table[b, 0] = mask.sum()` and, when the mask is non-empty, `table[b, 1] = conf[mask].mean()` and `table[b, 2] = correct[mask].mean()`. `expected_calibration_error`: with `filled = table[:, 0] > 0`, return `np.sum(table[filled, 0] / N * np.abs(table[filled, 2] - table[filled, 1]))`. `temperature_scale`: `losses = [mean_nll(logits, labels, t) for t in grid]; return float(grid[int(np.argmin(losses))])`, raising ValueError first if the grid is empty.
