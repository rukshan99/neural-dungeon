`EvalSuite.run` is a for-loop that never crashes: wrap `system_fn(case.input)` and `scorer(case, output)` in one `try`, and on any exception record `output = f"ERROR: {type(exc).__name__}: {exc}"` with score 0.0. Build a `CaseResult` per case, then `score = mean of case scores` and `by_tag[t] = mean over cases whose tags contain t`. Scorers are tiny: `exact_match` compares stripped strings, `contains` lowercases both sides and uses `in`, `numeric_tolerance` and `judge_scorer` return inner functions (closures).
---
For markdown, build a list of lines and `"\n".join` them: a heading, `Overall score: {score:.3f} ({n_passed}/{n} passed)`, a `| tag | score | cases |` table, then a `| id | tags | expected | output | score | passed |` table with one row per case. Escape pipes inside cells with `str(text).replace("|", "\\|")`. For JSON, `dataclasses.asdict(result)` turns each `CaseResult` into a dict; `to_dict` returns `{"score": ..., "by_tag": ..., "per_case": [...]}` and `from_dict` rebuilds `CaseResult(**{**r, "tags": tuple(r["tags"])})` because JSON turned the tuples into lists.
---
`numeric_tolerance`: `m = re.search(r"-?\d+(?:\.\d+)?", output)`; no match is 0.0, otherwise compare `abs(float(m.group()) - float(case.expected)) <= tol`. `judge_scorer`: `(llm_judge(llm, case.input, output, rubric).score - low) / (high - low)`. `compare_to_baseline`: index the baseline by id (`{r.id: r for r in baseline.per_case}`), walk `report.per_case` in order and emit `Regression("case", r.id, old.score, r.score, msg)` when `old.passed and not r.passed`; then, if `baseline.score - report.score > tolerance`, append one `Regression("overall", None, baseline.score, report.score, msg)`.
