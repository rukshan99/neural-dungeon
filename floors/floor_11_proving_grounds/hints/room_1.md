Everything is a count. Build the confusion matrix first: `cm[i, j]` is how many examples have true class `i` and predicted class `j`. For a binary problem with positive class 1, TP is `cm[1, 1]`, FP is `cm[0, 1]` (predicted 1, actually 0) and FN is `cm[1, 0]`. Then every metric is a ratio of those, and every zero-division case is a denominator of 0 that you replace with 0.0. For perplexity, remember the order: mean first, then exp.
---
`np.add.at(cm, (y_true, y_pred), 1)` increments one cell per example and does not lose duplicates the way `cm[y_true, y_pred] += 1` does. For precision/recall, boolean masks are cleanest: `t = y_true == positive; p = y_pred == positive; tp = (t & p).sum(); fp = (~t & p).sum(); fn = (t & ~p).sum()`. Macro-F1 and balanced accuracy are `np.mean([precision_recall_f1(y_true, y_pred, positive=c)[k] for c in range(n_classes)])` with `k = 2` for F1 and `k = 1` for recall; infer `n_classes` as `max(y_true.max(), y_pred.max()) + 1` when it is None.
---
`precision = tp / (tp + fp) if tp + fp else 0.0`, same shape for recall, and `f1 = 2 * p * r / (p + r) if p + r else 0.0`. Wrap results in `float(...)` so the trial does not see numpy scalars. `perplexity_from_nll` is `float(np.exp(np.mean(nll)))`; `token_level_perplexity` is `float(np.exp(-np.mean(log_probs)))` (mind the minus: log-probs are negative). Raise `ValueError` when the input is empty; `np.mean([])` would give a NaN and a warning instead.
