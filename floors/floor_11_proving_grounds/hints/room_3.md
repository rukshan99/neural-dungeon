Three separate problems. The prompt: put the criteria, both ends of the scale and the exact JSON shape you want in the system message, and the question plus answer in the user message. The parse: models wrap JSON in fences and prose, so look for the first `{ ... }` you can `json.loads`, and only give up when there is truly no score. The bias: `pairwise_judge_debiased` calls the naive judge twice, once with `(a, b)` and once with `(b, a)`, and only declares a winner when the two calls agree about which TEXT won.
---
For parsing, strip fences first (`re.findall(r"```[a-zA-Z]*\s*(.*?)```", text, re.DOTALL)`) and try each chunk plus the whole text; inside a chunk, scan for a `{`, walk forward counting braces until depth returns to 0, and `json.loads` that slice. Coerce the score with `int(round(float(obj["score"])))` so `"4"` and `4.0` both work. In the swapped call an `"A"` verdict means b won, so translate: `winner_second = "B" if second == "A" else "A"`, then compare with the first verdict. Kappa: `p_o = np.mean(a == b)`, `p_e = sum(np.mean(a == k) * np.mean(b == k) for k in np.union1d(a, b))`.
---
Average ranks: `order = np.argsort(x, kind="stable")`, walk the sorted values in runs of equal value from position i to j, and assign every member of the run the rank `(i + j) / 2 + 1`. Spearman is then Pearson on the ranks: centre both rank arrays, `np.sum(rx * ry) / np.sqrt(np.sum(rx**2) * np.sum(ry**2))`, returning 0.0 when the denominator is 0. `cohens_kappa` returns 1.0 when `p_e >= 1`. `agreement_report` is a dict of `n`, `kappa`, `spearman`, `exact_agreement = np.mean(j == h)` and `mean_abs_diff = np.mean(np.abs(j - h))`.
