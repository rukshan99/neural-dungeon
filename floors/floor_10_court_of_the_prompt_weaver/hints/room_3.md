`backoff_delay`: `ceiling = min(cap, base * 2**attempt)`; return `ceiling` when `jitter` is False, else `(rng or random).uniform(0.0, ceiling)`. In `with_retries`, loop `for attempt in range(max_attempts):` with `try: return fn()` and `except retry_on as exc:`. Anything not in `retry_on` is simply not caught, which is exactly "propagates immediately".
---
Inside the `except`: remember `exc`; if `attempt == max_attempts - 1`, `break` (no sleep after the last failure). Otherwise `delay = backoff_delay(attempt, base, cap, True, rng)`; `retry_after = getattr(exc, "retry_after", None)`; if it is not None, `delay = max(delay, retry_after)`; call `on_retry(attempt + 1, exc, delay)` if given; `sleep(delay)`. After the loop: `raise RetriesExhausted(max_attempts, last) from last`. `Idempotent.__call__`: compute the key, return `self.cache[key]` if present, otherwise run `fn`, increment `executions`, store and return. Do not store anything if `fn` raised (the exception propagates before the store).
---
`CircuitBreaker.state`: if `_state` is open and `clock() - _opened_at >= recovery_time`, set `_state = HALF_OPEN`; return `_state`. `allow()` is `self.state != OPEN`. `record_success`: failures = 0, state closed. `record_failure`: `failures += 1`; if `self.state == HALF_OPEN or failures >= failure_threshold`: state open and `_opened_at = clock()`. `call(fn)`: if not `allow()`, raise `CircuitOpen`; `try: result = fn()` / `except Exception: record_failure(); raise` / then `record_success()` and return.
