`extract_json`: strip the fence with a regex like `` ```[a-zA-Z0-9_-]*\s*\n?(.*?)``` `` (DOTALL), then scan character by character from the first `{` or `[`. Keep a stack of openers and a flag for "inside a string"; while inside a string, only `\` (skip the next char) and `"` (leave the string) matter. When the stack empties you have the end. `validate` is a recursive function with a `path` parameter that grows: `f"{path}.{key}"` for properties, `f"{path}[{i}]"` for items.
---
Type checks are the one place Python bites: `isinstance(True, int)` is True, so "integer" must be `isinstance(v, int) and not isinstance(v, bool)`; "number" is `isinstance(v, (int, float))` with the same bool exclusion; `3.0` is a float, so it is not an integer. If the type is wrong, return that single error for the node and do not check anything else there. The Python type name in the message is `type(v).__name__` ("str", "list", "bool"); None is "null".
