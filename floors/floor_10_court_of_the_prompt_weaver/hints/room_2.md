`Tool.spec()` is `ToolSpec(self.name, self.description, self.parameters)`. The registry is a dict from name to Tool; `specs()` is a list comprehension over its values. In `call`, look the name up first: a missing tool returns a string starting with `TOOL_ERROR_PREFIX` that lists `sorted(self._tools)`. Then `try: result = tool.fn(**(arguments or {}))` and `except Exception as exc:` return another `TOOL_ERROR_PREFIX` string with `type(exc).__name__` and `exc`. Strings pass through; anything else goes through `json.dumps`.
---
The loop: `history = list(messages)`, then `for step in range(1, max_steps + 1):` call `completion = llm.complete(history, registry.specs())` and `history.append(completion.message)` (this message already carries the `tool_calls`). If `completion.stop_reason != "tool_use"` or there are no tool calls, `return AgentResult(completion.text, history, step, tool_calls_made)`.
---
Otherwise, `for call in completion.tool_calls:` do `result = registry.call(call.name, call.arguments)` and `history.append(Message.tool(call.id, result, name=call.name))`, counting each. Every call in the completion gets exactly one tool message, in the same order. When the `for step` loop falls through, `raise StepBudgetExceeded(...)`: the model was called `max_steps` times and still wanted more.
