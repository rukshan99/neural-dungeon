Start with the state. `__init__`: `self.vocab = {i: bytes([i]) for i in range(256)}`, `self.merges = []`, `self.ranks = {}`, `self.unk_id = None`. `pretokenize` is `PIECE_PATTERN.findall(text)`. `merge_ids` is `merge_pair` from room 5.2 with ints instead of strings and an explicit `new_id`. In `train`, reset the state first, then count pieces: `key = tuple(piece.encode("utf-8"))` into a dict of counts. Each round: count adjacent pairs over the piece dict (weighted), `best = min(counts, key=lambda p: (-counts[p], p))`, `new_id = len(self.vocab)`, `self.vocab[new_id] = self.vocab[a] + self.vocab[b]`, record the rank, append the merge, rewrite every piece with `merge_ids`. Stop when `len(self.vocab) == vocab_size` or no pairs are left.
---
`encode`, per piece: `ids = list(piece.encode("utf-8"))`, then loop: among `zip(ids, ids[1:])` find the pair with the smallest `self.ranks.get(pair)` (skip pairs with no rank); if none, break; else `ids = merge_ids(ids, best, 256 + rank)`. Cache the result per piece; the Chronicles repeat themselves. The invariant that makes `256 + rank` correct: merge number `k` created id `256 + k`.
---
`decode`: `b"".join(self.vocab[int(i)] for i in ids).decode("utf-8", errors="replace")`. `unknown_rate`: `unk = getattr(tokenizer, "unk_id", None)`; return `0.0` if `unk is None` or the id list is empty; otherwise `ids.count(unk) / len(ids)`. `compression_ratio`: `len(text.encode("utf-8")) / len(ids)` with a `0.0` guard for zero tokens. If phase 4 fails but phases 1 to 3 pass, check that `encode` actually consults `self.ranks` and that `train` merges the most frequent pair rather than the first one it sees.
