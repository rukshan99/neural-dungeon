`word_counts`: `for word in text.split(): key = (*word, END_OF_WORD)` and count keys in a dict. `pair_counts`: for each word tuple with count `n`, walk `zip(symbols, symbols[1:])` and add `n` to each pair. Nothing crosses a word boundary because you never look at two words at once.
---
`merge_pair` is an index loop: `while i < len(symbols)`, if `symbols[i] == a and symbols[i + 1] == b` (guard `i + 1 < len`), append `a + b` and skip two, else append one symbol and skip one. `train_bpe`: repeat `num_merges` times: `pairs = pair_counts(words)`; stop if empty; `best = min(pairs, key=lambda p: (-pairs[p], p))` (highest count, then smallest pair); append it; rebuild `words` by applying `merge_pair(symbols, best)` to every key.
---
`encode_bpe`: for each word, `symbols = (*word, END_OF_WORD)`, then `for pair in merges: symbols = merge_pair(symbols, pair)`, extend the output. Caching by word makes the page tests instant. `decode_bpe`: `"".join(tokens).replace(END_OF_WORD, " ").rstrip(" ")`. Prophecy: in the tiny corpus `(u, g)` and `(g, </w>)` both count 4 (three hugs, one pug); `"g" < "u"`, so `(g, </w>)` binds first. Then `(u, g</w>)` at 4, then three pairs tie at 3 and `"h"` is the smallest first element.
