Attention is four reshapes around one matrix product. `self.c_attn(x)` is `(B, T, 3D)`; `q, k, v = qkv.split(D, dim=2)` in that order; each becomes `(B, H, T, hd)` via `.view(B, T, H, hd).transpose(1, 2)`. Scores are `q @ k.transpose(-2, -1) / math.sqrt(hd)`, shape `(B, H, T, T)`: row = query position, column = key position.
---
The mask: `mask = torch.tril(torch.ones(block_size, block_size, dtype=torch.bool)).view(1, 1, block_size, block_size)` and `self.register_buffer("mask", mask, persistent=False)`. In forward: `att = att.masked_fill(~self.mask[:, :, :T, :T], float("-inf"))`, then `F.softmax(att, dim=-1)`, `y = att @ v`, `y = y.transpose(1, 2).contiguous().view(B, T, D)`, `return self.resid_dropout(self.c_proj(y))`.
---
The block is four lines: `self.ln_1 = LayerNorm(n_embd, bias=bias)`, `self.attn = CausalSelfAttention(n_embd, n_head, block_size, bias, dropout)`, `self.ln_2 = LayerNorm(n_embd, bias=bias)`, `self.mlp = MLP(n_embd, bias, dropout)`; forward is `x = x + self.attn(self.ln_1(x)); x = x + self.mlp(self.ln_2(x)); return x`. If shapes pass but the reference-weights trial fails: check the split order (q, k, v), that you divide by sqrt(hd) not sqrt(D), and that softmax is over the last dim.
