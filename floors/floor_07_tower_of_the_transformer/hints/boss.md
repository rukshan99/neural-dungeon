Phase 1 is plain Python on lists. `distinct_ngram_ratio`: `grams = [tuple(ids[i : i + n]) for i in range(len(ids) - n + 1)]`, return `len(set(grams)) / len(grams)` (and 0.0 if there are none). `repetition_penalty`: clone, then per row `seen = torch.unique(generated_ids[b])`, `vals = out[b, seen]`, `out[b, seen] = torch.where(vals > 0, vals / penalty, vals * penalty)`. `block_repeated_ngrams`: `prefix = tuple(seq[-(n - 1):])` (empty tuple when n is 1), then ban `seq[i + n - 1]` for every `i` where `tuple(seq[i : i + n - 1]) == prefix`.
---
Phase 2 walks the sequence in windows of `B = model.cfg.block_size`: `for start in range(0, len(ids) - 1, B): y = ids[start + 1 : start + 1 + B]; x = ids[start : start + len(y)]; logits, _ = model(x[None]); total += F.cross_entropy(logits[0], y, reduction="sum").item(); count += len(y)`. Return `total / count`, under `torch.no_grad()`, in eval mode.
