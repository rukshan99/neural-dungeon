Build the parts in the order of the docstring: `self.wte`, `self.wpe`, `self.drop`, `self.blocks = nn.ModuleList([Block(cfg.n_embd, cfg.n_head, cfg.block_size, bias, dropout) for _ in range(cfg.n_layer)])`, `self.ln_f`, `self.lm_head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False)`. Then the tie, which is an assignment of the Parameter itself: `self.lm_head.weight = self.wte.weight`. Read `dropout` and `bias` with `getattr(cfg, "dropout", 0.0)` so a plain object works.
---
Init in two passes. `self.apply(self._init_weights)` where the function does `nn.init.normal_(m.weight, 0.0, 0.02)` for `nn.Linear` and `nn.Embedding` and `nn.init.zeros_(m.bias)` for Linear biases. Then `for name, p in self.named_parameters(): if name.endswith("attn.c_proj.weight") or name.endswith("mlp.proj.weight"): nn.init.normal_(p, 0.0, 0.02 / math.sqrt(2 * cfg.n_layer))`. `num_params` is `sum(p.numel() for p in self.parameters())`, minus `self.wpe.weight.numel()` when `non_embedding`.
---
Forward: `B, T = idx.shape`; `if T > self.cfg.block_size: raise ValueError(...)`; `pos = torch.arange(T, dtype=torch.long, device=idx.device)`; `x = self.drop(self.wte(idx) + self.wpe(pos))`; loop the blocks; `logits = self.lm_head(self.ln_f(x))`; `loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1))` if targets is not None else None; `return logits, loss`. If the checkpoint loads but the loss differs, the parts are right and the order is wrong.
