# Code of Conduct

Neural Dungeon is a place to learn hard things in public. That only works if everyone feels safe being a beginner at something.

## We expect

- **Kindness to learners.** Every question is a good question. "Read the docs" is not an answer; a link to the right part of the docs is.
- **Kindness to contributors.** Review the work, not the person. Assume good intent, and say what you liked before what you would change.
- **Jokes that punch at tensors, not people.** The dungeon's humour is about shapes, gradients and fictional adventurers. It never targets identity, ability, background, language or experience level, and it never depends on knowing a particular culture or workplace.
- **Honesty about correctness.** If a room teaches something wrong, say so plainly and fix it. Rigour is a kindness to future learners.

## We do not tolerate

Harassment, discrimination, demeaning comments, unwelcome sexual attention, doxxing, or sustained disruption, in issues, pull requests, discussions or any other project space.

## Enforcement

Report concerns to the maintainer through a GitHub issue marked private-if-needed, or by email to the address on the maintainer's GitHub profile. Reports are handled confidentially. Consequences range from a private conversation to removal from the project, at the maintainer's discretion.
